# 核查任务定义

状态：用户于 2026-10-13 确认第一版范围、舍入规则、稿内一致性与出处库范围。本文件只定义任务合同；阶段与进度见 [plan.md](plan.md)，来源核实记录见 [result.md](result.md)。

## 范围

输入是一篇中文研报或点评草稿，以及限定范围的出处库。出处库第一批即包含公司定期报告、更正公告、政策文件与统计数据。系统对稿件中可核对的断言逐条给出结论。第一版只处理数值、日期与出处标注三类；政策或公告文字的引述留到后续版本。投资观点、预测、评级不属于可核对断言，一律不判。

## 断言

一条断言是稿件中可与出处对照的一个最小陈述。

| 字段 | 含义 |
|---|---|
| `claim_id` | 稿内唯一编号 |
| `span` | 断言在稿件中的字符起止位置 |
| `kind` | `direct`（直接引用的数值）、`derived`（由其他数值推导，如同比、占比、差额）、`date`（文件或事件日期）、`source`（出处标注） |
| `entity` | 公司或发布机构 |
| `metric` | 指标名，按稿件原文记录 |
| `scope` | 口径：合并／母公司、归属于母公司、扣除非经常性损益等；稿件未写明时记为未指明 |
| `period` | 报告期或时点 |
| `value`、`unit`、`scale`、`currency` | 稿件写出的数值、单位、量级与币种 |
| `stated_source` | 稿件自己标注的出处；没有则为空 |
| `derivation` | 仅 `derived`：运算及其操作数（指向其他断言或出处事实） |

## 核查结论

| 结论 | 判定条件 | 必须附带 |
|---|---|---|
| 一致 | 在出处库中找到指标、口径、期间均对应的事实，换算量级后数值相符 | 出处位置；推导类附重算过程 |
| 不一致 | 找到对应事实，但数值、单位、期间、口径、日期之一不符 | 错误类别、原文值与位置 |
| 找不到依据 | 在允许范围内未检索到对应事实 | 已检索的范围 |
| 口径不明 | 存在多个候选事实，或稿件口径、期间不足以唯一确定 | 候选事实与缺少的信息 |

后两种都交给人，系统不替人下结论。

数值相符的规则：先按单位与量级换算到同一尺度；稿件数值按其自身显示的小数位理解，与原文值（或重算值）之差不超过末位半个单位记为一致，超过半个但不超过一个单位记为一致并标注“舍入差”，更大记为不一致。计算一律由受控 Decimal 工具执行。

## 错误类别

| 编号 | 类别 | 例 | 依据 |
|---|---|---|---|
| E1 | 数值与原文不符 | 营收写 123.4 亿元，原文 132.4 亿元 | 调研转述的罚单事由“引用信息与原文不一致”（逐份罚单未核实） |
| E2 | 单位或量级错 | 万元写成亿元、千写成百万 | 尚无直接依据，属推断（公开财报问答数据集的标签中见过千与百万混淆） |
| E3 | 期间错位 | 引用的是上一年度或另一季度的数 | 同 E1 |
| E4 | 口径错位 | 把净利润当作归母净利润 | 同 E1 |
| E5 | 推导错误 | 同比、占比与所引原值重算不符 | 双随机检查通报：“计算方法”底稿不完整（已核实） |
| E6 | 版本失效 | 引用更正公告之前的数值 | 本项目康美药业、新纶科技更正案例 |
| E7 | 日期错误 | 把旧政策或旧文件标为新日期 | 2026-06 地产周报事件（已核实） |
| E8 | 出处缺失或不可核实 | 数据未标出处，或所标出处中没有该数据 | 双随机检查通报：“数据信息未标明出处、来源标注不明确”（已核实） |
| E9 | 稿内不一致 | 同一数据在摘要、正文、表格中不同 | 尚无直接依据，属推断；用户决定纳入第一版 |

## 指标

- 检出率：评测集中的错误被判为“不一致”且类别正确的比例；另报不计类别的检出率。
- 误报率：正确断言被判为“不一致”的比例。
- 自动核对比例：得到“一致”或“不一致”结论的断言占全部断言的比例。
- 交给人的比例：“找不到依据”与“口径不明”合计占比。
- 抽取质量单列：漏抽与错抽的断言不计入上述分母，单独报告。

舍入规则尚无从业者依据，为用户确认的工作假设。
