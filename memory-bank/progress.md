# 当前进度

更新：2026-10-15。

- **项目定位：研报发布前质控预审 Agent。** 定位、设计决定与七个阶段见 [plan.md](plan.md)。
- **阶段 0（定义任务）完成。** 调研的 5 个关键来源已核对原文，记录见 [result.md](result.md)；任务定义已由用户确认，记录同上。尚无质控人员或分析师的一手访谈。
- **阶段 1（出处库）完成（2026-10-14）。** 出处库 `data/staged/library_v3/library.sqlite`：30 家发行人 2023—2025 财年年度报告 90 份与更正公告 2 份、政策与统计发布 1,855 篇，共 27,079 页文本和 537,077 条带原文字符位置的表格事实；支持按数字查找、按发行人与截止日过滤的页面检索。核查情况与已知缺口（均记在 [result.md](result.md)）：相邻年度年报的自动交叉验证印证了 69,915 条事实（13.1%）的数值、行标签与列角色，两边都有单位时单位不一致率 0.35%；12 页 260 条整页人工核对中，能对照页面图的 191 条行列归属无误，发现 5 条单位或类型错误并已修规则；修订后未再人工核对。仍有 15.2% 的事实没有单位、15.2% 没有列表头；8.6% 的页面有数字无法与文本层对照（部分页面是图片）；期间未规范化；更正公告未与原报告建立替换关系；检索只有 BM25 且未评测；住建部文件未取得。
- **阶段 2（评测集）v2 已冻结（2026-10-14）**：`data/staged/eval_v2/`（取代未使用过的 v1）。注入 9 类错误的断言：训练 38,798／开发 2,049／验收 2,038 条，覆盖 28／30 家发行人（缺紫金矿业、格力电器），另含康美药业、新纶科技两个真实更正案例；两个模型写的 352 篇年报点评共 12,309 个数字已由 Codex 逐条核实（盲审一致率 96.9%—99.1%，标注在 `data/staged/eval_v2_labels/`，已进 Git，页面截图除外）：不给原文时 77%—84% 的数字错误，给原文时 7%—12%。API 累计约 1.07 美元。详见 [result.md](result.md)。
- **阶段 3（免训练基线）完成（2026-10-14）**：抽取（flash，科目从年报合并报表清单中选择）＋确定性核查。训练集独立检验（6,830 个数字，规则开发中未查看）：错误数字判出 62.7%、非舍入错误放行 2 个，正确数字确认 75.4%、误报 4.1%（集中在银行）；对照组“flash 读原文直接审稿”非舍入错误放行 323 个，其中给原文写成的稿件中 320 个错误只判出 6 个。详见 [result.md](result.md)。
- **阶段 4（训练）完成（2026-10-15）**：4×4090 FSDP 训练 Qwen3.5-9B LoRA 抽取模型（40 分钟）。开发集上误报 7、遗漏 4、正确确认 913、非舍入放行 0，优于免训练（46／77／834）且误报、遗漏少于 flash（10／18）；核查器比率符号漏洞在看过开发集后修正，故为有条件通过，以阶段 6 验收集为准。详见 [result.md](result.md)。机器已换回单卡。
- **阶段 5（产品化）完成（2026-10-15）**：LangGraph 流程（抽取 Agent → 核查器 → 复查 Agent → 修订 Agent → 底稿）、本机审核页面、MCP 工具与故障处理。单 Agent 对照在开发集上放行 14 个真实错误，混合流程（复查 Agent 只能加报警）开发集判出 93.4%、非舍入放行 0。
- **阶段 6（验收）完成（2026-10-15）**：验收集 94 篇 3,256 个数字一次性评估，H1—H5 全部通过：混合流程判出 95.3% 错误、非舍入放行 0、误报 2.95%；本地 9B LoRA 可替代 flash 抽取；flash 直接审稿放行 111 个错误。主要遗留瓶颈是出处库对格力、比亚迪、迈瑞的报表绑定，导致约一半正确数字仍需人工（多数带 Agent 提示）。
